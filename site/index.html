Run a fleet of AI coding agents without frying your brain.

Agents made it cheap to run ten things at once. The part that didn't scale is you — tracking which one is stuck, and carrying a model of every project in your head. That ceiling is what Kod is built to lift.

Kod is early. It is built and used daily by one person, and rough edges are real: text fields do not accept paste yet, projects cannot be deleted, and the map and memory surfaces are compiled out by default. If that is interesting rather than disqualifying, the issues are the honest list.

You shouldn't have to track what's running

Which of your agents is working, which is idle, which hit a usage limit, which has been sitting on a question for twenty minutes. That is state a machine should hold, not a person. Kod keeps it across every project and puts whatever is blocked at the top.

Standup

One reactive home across every project — and idle-time summaries of what each session got done, so catching up is reading four lines instead of scrolling four transcripts.

Profiles

Named per-CLI accounts, isolated by CLAUDE_CONFIG_DIR and CODEX_HOME. Run two claude accounts and pick one per session.

Recover

Sessions that crashed, or that you started in a terminal somewhere and lost track of, are findable and resumable — losing one stops meaning losing its context.

You shouldn't have to watch for it

Polling twelve tabs to see if anything needs you is the tax that makes running several agents exhausting. Kod pulls you back instead: a notification the moment an agent is genuinely blocked, and a count on the Dock icon the rest of the time — ambient, never interrupting. A background daemon owns the sessions, so closing the window doesn't kill the work.

You shouldn't have to hold the project in your head in progress

The last load, and by far the largest. Not what your agents are doing — what the project is.

Every project you run lives as a model in your head: what it is, what you decided and why, what you ruled out, what comes next. That model is the real ceiling — not how many agents you can start, but how many projects you can keep a model of at once. Kod is growing a memory system to put that model down: you offload the thinking into it, and the map draws it back as something you can look at. Picking a project up after two weeks becomes reading, not remembering — and your agents work against the same model rather than whatever you can recall to tell them.

The memory and the map ship behind default-off feature flags today, because neither is finished. They are in the source if you want to read where it is going.

Install

Signed with a Developer ID and notarized by Apple, so it opens without a warning. 

# Kod.dmg — open it and drag Kod.app to Applications
Download Kod.dmg   ·   all releases

Or build it yourself:

git clone https://github.com/FelisAI/kod.git
cd kod/app
cargo run -p orchestrator-gui

Requires macOS 13 or newer, a Rust toolchain via rustup (the pinned version installs itself), and the Xcode Command Line Tools. You'll also want claude and/or codex on your PATH — Kod orchestrates them, so without at least one it has little to do. The first build takes a few minutes; later ones are incremental.

Named after the kodkod (Leopardus guigna), the smallest wild cat in the Americas. Small, quiet, always watching.
